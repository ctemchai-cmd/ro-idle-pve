# สำรองและกู้คืนเซฟ (สำหรับผู้เล่น)

เซฟหลักอยู่บนคลาวด์ ทุกครั้งที่บันทึก เซิร์ฟเวอร์จะลงลายเซ็นไว้ เกมจึงไม่ยอมรับเงินหรือไอเทมที่แก้จากไฟล์เอง เมนูอยู่ที่ **ตั้งค่า › 💾 สำรอง / กู้คืนเซฟ**

## ส่งออกไฟล์สำรอง
กด **ดาวน์โหลดไฟล์สำรอง** จะได้ไฟล์ `ro-idle-backup-r<เลข>-<วันที่>.json` เป็นสำเนาเซฟล่าสุดบนคลาวด์ ในไฟล์ไม่มีรหัสผ่าน token หรืออีเมล

## ตรวจไฟล์สำรอง
กด **เลือกไฟล์ .json** เกมจะแสดงตารางเทียบระหว่างคลาวด์กับไฟล์: ตัวหลัก ทอง Crystal EXP ไอเทม ด่าน และชั้นหอคอย
- ใช้ดูอย่างเดียว ไม่เขียนทับเซฟบนคลาวด์
- ถ้าไฟล์เก่ากว่า คลาวด์ยังเป็นตัวจริงต่อไป
- ถ้าค่าตรวจสอบไม่ตรง แปลว่าไฟล์ถูกแก้

## เริ่มเกมใหม่ และย้อนกลับ
1. เปิด **โซนอันตราย › เริ่มเกมใหม่…** เลือกสายและเพศ แล้วพิมพ์ `RESET`
2. ก่อนลบ เกมจะสำรองเซฟเดิมไว้บนคลาวด์ให้อัตโนมัติ
3. ถ้าเปลี่ยนใจ ไปที่ **จุดสำรองบนคลาวด์** แล้วกด **กู้คืน** ที่แถว "ก่อนเริ่มเกมใหม่" ทำได้ครั้งเดียวต่อการรีเซ็ตแต่ละครั้ง

สิ่งที่ไม่ย้อนกลับ:
- เวลา AFK
- สิทธิ์ดันเจี้ยนรายวันของวันนี้
- จำนวนที่ซื้อในร้านค้าวันนี้

## เมื่อเกมแจ้งว่าต้องอัปเดตเซฟ
หลังเกมอัปเดต เซฟรุ่นเก่าจะแสดงตาราง "เดิม / หลังอัปเดต" กด **สำรองแล้วอัปเดตเซฟ** ระบบจะเก็บเซฟเดิมเป็นจุดสำรอง "ก่อนอัปเดตเซฟ" ก่อนเสมอ ไฟต์ที่ค้างอยู่จะจบลง ถ้าเกมแจ้งว่าไม่รองรับ เซฟเดิมจะยังอยู่ครบ ให้รอเกมเวอร์ชันถัดไป

## เมื่อเกมแจ้งว่าเซฟตรวจสอบไม่ผ่าน
แปลว่าข้อมูลบนคลาวด์ไม่ตรงกับลายเซ็น เช่นมีการแก้ไขฐานข้อมูลโดยตรง เกมจะเสนอ **กู้คืนเซฟ #N** โดยใช้จุดล่าสุดที่ลายเซ็นถูกต้อง ข้อมูลที่เสียจะถูกเก็บแยกไว้ ถ้าไม่พบจุดที่ถูกต้อง เกมจะไม่แก้อะไรเลย ให้ผู้ดูแลกู้คืนจากสำรองฝั่งเซิร์ฟเวอร์ เช่น `play_local.py` ที่สำรองฐานข้อมูลไว้ก่อนทุกครั้ง
