## เป้าหมายและผลส่งมอบ

- performance/loading report และการแก้คอขวดที่วัดได้

## ขอบเขต

- รวม: ผลลัพธ์ที่ระบุในชื่อและรายละเอียดงานนี้ตามข้อมูลรุ่นแรกที่ review แล้ว
- อยู่นอกงาน: การพัฒนาระบบ Hi-class/Awaken/Artifact, Class 3/Pet/Rune, dashboard หรือ AI ค้นบิลด์อัตโนมัติ; ส่วนอนาคตบันทึกจุดต่อไว้ตาม design

## รายละเอียด

ตาม D-052 เกมรองรับแนวตั้งเท่านั้น: ตรวจจอ 360×740, 390×844 และกรอบแนวตั้งบน desktop; มือถือแนวนอนตรวจเพียงว่าขึ้นข้อความให้หมุนเครื่อง ไม่ต้องมี layout แนวนอน วัด initial download/ตามฉาก, memory/frame time ในไฟต์หนักและ event throughput ใน runner ตามอุปกรณ์ scope ปรับ cache/lazyload/dispose/resource limits โดยไม่เปลี่ยนผล combat ตรวจขนาดให้ตรงช่องทาง Vercel ที่จะใช้

## ขั้นตอนทำงาน

1. สร้าง production build และวัดบนอุปกรณ์/ความเร็วเน็ตที่ระบุ
2. หาและแก้จุดโหลดเกิน/texture หรือ audio ไม่คืน/งาน main thread หนัก
3. เปรียบเทียบผล engine ก่อนหลังและวัดซ้ำเฉพาะจุดแก้
