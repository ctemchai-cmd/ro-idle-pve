# TASK-045 — deploy Production และตรวจบัญชี/เซฟจริง

Milestone: M4 · ประเภท: พัฒนา/ตรวจรับรุ่นแรก · รุ่น: Class 2 / Lv.70

อ้างอิง: [เซฟและ deploy](../design/07-cloud-save-and-deployment.md), [ข้อสรุป](../decisions.md), [workflow](../workflow.md)

## งานที่ต้องรอก่อนหน้า

- TASK-044 — ตรวจรับรุ่น Class 2 บน release candidate

ใช้ผลส่งมอบที่ผ่าน review ของงานข้างต้นตามรายละเอียดงานนี้ อ้างด้วย ID และค้นไฟล์จากโฟลเดอร์สถานะปัจจุบัน

## เป้าหมายและผลส่งมอบ

- production URL พร้อม Auth/ฐานข้อมูล/pack รุ่นที่ตรวจรับแล้ว
- deployment/migration/rollback record และผล smoke test

## ขอบเขต

- รวม: ผลลัพธ์ที่ระบุในชื่อและรายละเอียดงานนี้ตามข้อมูลรุ่นแรกที่ review แล้ว
- อยู่นอกงาน: การพัฒนาระบบ Hi-class/Awaken/Artifact, Class 3/Pet/Rune, dashboard หรือ AI ค้นบิลด์อัตโนมัติ; ส่วนอนาคตบันทึกจุดต่อไว้ตาม design

## รายละเอียด

นำ releasecandidate ที่ผ่านแล้วขึ้น Vercelproduction ตั้ง env/redirect/privateaccount และ migrations ตรงกัน ใช้ sourcepack ที่ตรวจรับ ไม่คัดลอก previewsave ทับของจริง สำรองก่อนเปลี่ยนข้อมูลเดิมและมีวิธีย้อนรุ่น

## ขั้นตอนทำงาน

1. ตรวจ config/backup/migration และ deploymentversion ก่อนปล่อย
2. deployproduction ตามขั้นตอน TASK-043 แล้วเชื่อมบัญชีส่วนตัว
3. ตรวจ login/play/save/reopen/reward และบันทึกวิธีย้อนรุ่นโดยไม่ลบข้อมูล

## เกณฑ์ตรวจรับ

- [ ] AC-01: production เปิด URL จริงแล้วเข้าอีเมล/รหัสผ่านและเล่น/save-load ได้
- [ ] AC-02: production ใช้ข้อมูล/credentials ของ env ถูกต้อง ไม่ปน preview และไม่เผย secret หรือคลัง asset ทั้งหมด
- [ ] AC-03: smoke test หลัง deploy ไม่มี 404/ข้อผิดพลาดสำคัญและไม่สร้างรายการทดสอบค้างในเซฟจริง
- [ ] AC-04: ระบุ build/content/migrationversion กับ backup/rollback ที่ทำตามได้และไม่อ้างว่าทดสอบสิ่งที่ยังไม่เคยลอง

## วิธีตรวจและหลักฐาน

smoke test หลัง deploy และตรวจ owner/env/assetrequests อย่างจำกัด เก็บผลที่ไม่เปิดเผย credentials หรือข้อมูลส่วนตัว
