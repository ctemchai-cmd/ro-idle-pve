# เลเวล อุปกรณ์ การ์ด และ Artifact

สถานะ: ใช้ฐาน P-04–P-06 และ cap รุ่นแรก Lv.70 แล้ว; ต้นทุน/สูตรค่าจริงเป็นงานออกแบบต้นทาง

TASK-001 ส่ง baseline เลเวล/แต้ม/ทรัพยากร/ปลดระบบ/คืนทุนแล้วใน [release scope](09-release-scope.md) และ [progression data](../data/progression.json) ค่าในข้อมูลชุดนี้เป็นฐานให้ TASK-002–013 ทำต่อ ยังไม่ใช่ผลวัด pace หรือระบบเกมที่สร้างเสร็จ

## ตัวละครและ Breakthrough

ยืนยัน: อัปเลเวลตัวหลักและเพื่อนได้ มี Breakthrough ทุก 20 เลเวล และ skill cap ขึ้นกับเลเวลตัวละคร

ระดับเปลี่ยนคลาส: **Class 2 Lv.20 → Hi-class Lv.70 → Class 3 Lv.120** ตาม D-024 การเปลี่ยนคลาสและ Breakthrough เป็นคนละเงื่อนไข ไม่เพิ่ม Breakthrough พิเศษที่ 70 รุ่นแรกถึง Class 2 และเพดานเลเวล 70 ตาม D-028; Hi-class/Awaken/Artifact อยู่ milestone ถัดไป

P-04: รักษาเลเวลเมื่อเปลี่ยนคลาส รีเซ็ต Status/Skill และสลับอาชีพนอกไฟต์ฟรี NPC คง Class 1 ของตนแต่เลือกสาขาได้ ตัวหลักเปลี่ยน Class 1 ได้ ของที่ใส่ไม่ได้กลับกระเป๋า คืนทรัพยากรบิลด์โดยต้องไม่เกิดการรับคืนซ้ำ ห้ามนำการรีเซ็ตเลเวลสกิล Awaken ไปรีเซ็ตตัวละครเป็น Lv.1

Q-021 ยืนยันว่าได้ resources จากฟาร์มแล้วเลือกกดอัปตัวละครที่ต้องการได้ ไม่ใช้ EXP/auto-level เฉพาะตัวลงสนาม TASK-001 เลือก hero_exp/gold และ essence สำหรับ Breakthrough ตามตารางใน progression data; gate20/40/60 เพิ่ม local cap เป็น40/60/80 โดย release cap70ยังครอบอยู่ ไม่มี bonus stats/speed อัตโนมัติจาก Breakthrough

## เจ้าของความก้าวหน้าของเพื่อน

ยืนยัน D-022: ความก้าวหน้าผูกกับ NPC แต่ละตัว ไม่ผูกกับช่องจัดทีม

- NPC แต่ละตัวเก็บเลเวล สกิล และค่าพัฒนา Refine/Enchant/การ์ดประจำ slot ของตน
- ถอด NPC ออกจากทีมไม่ล้างความก้าวหน้า เลือกกลับมาได้ค่าของตนเดิม
- ใส่ NPC คนใหม่ในช่องทีมเดิม ไม่คัดลอกหรือย้ายเลเวล/สกิล/ค่าพัฒนาจากคนก่อน
- ช่องทีมเก็บการเลือกสมาชิกและตำแหน่ง ส่วนข้อมูลถาวรของ NPC อยู่กับ roster
- Q-021: ใช้ resources เลือกกดอัป NPC ได้รวมตัวนอกทีม แต่เลเวล/แต้มยังเป็นของแต่ละตัว ไม่เพิ่มระบบแชร์เลเวลหรือ auto-level

ข้อมูลอุปกรณ์เป็นชิ้นและกระเป๋าต้องแยกจากข้อมูลพัฒนา slot เพื่อเปลี่ยนของแล้วคง Refine/Enchant/การ์ดตามบรีฟ รายละเอียดการสลับของระหว่างตัวละครต้องไม่สร้าง item instance หรือการ์ดซ้ำ

ใช้ definition/instance/slot sources ตาม [extension contracts](14-extension-contracts.md) ให้ไอเทม/การ์ด/Passive/status ใช้ modifiers/triggers ชุดเดียวกัน ถอด source หนึ่งแล้วไม่กระทบอีกแหล่ง และให้ stat preview/engine/simulation อ่านกติกาชุดเดียว

## Status ที่ยืนยันแล้ว

- ให้แต้มผู้เล่นลง STR/AGI/VIT/INT/DEX/LUK เองได้ทั้งตัวหลักและเพื่อน
- ไม่มีการเพิ่ม status ตามอาชีพอัตโนมัติ ผู้ใช้แก้จากคำตอบเดิมแบบโตตามอาชีพ + แต้มลงเอง เพราะไม่ต้องการให้การโตตามอาชีพเปลี่ยนจังหวะคิวโดยไม่ได้ตั้งใจ
- Baseline TASK-001: ทุก stat เริ่ม1, ให้5แต้มที่ยังไม่ลงต่อเลเวลเพิ่ม, ราคาเพิ่มแต้มตามตาราง และ manual stat สูงสุด99 โดยไม่ cap ผลรวมบัฟ สูตรแปลงเป็น ATK/HP/ASPD/Cast Speed ยังเป็น TASK-002; รีเซ็ตนอกไฟต์ฟรีตาม P-04
- ค่าตั้งต้นของตัวละครและการเติบโตของค่าต่อสู้พื้นฐานอื่น เช่น HP/ATK ยังต้องออกแบบแยก ไม่ตีความว่าอัปเลเวลเพิ่ม AGI/DEX หรือความเร็วให้อัตโนมัติ

ข้อเสนอ UI: แสดง SI/CT/ACD ที่เปลี่ยนก่อนยืนยันลงแต้ม/เปลี่ยนของ เพื่อให้จัดจังหวะได้ การเปลี่ยนความเร็วจากอุปกรณ์ Passive บัฟและ debuff ยังเป็นไปได้ตามสกิลที่ออกแบบ ต้องระบุผลชัดเจน; การไม่โตตามอาชีพไม่ได้ล็อกความเร็วคงที่ตลอดการต่อสู้

## อุปกรณ์ที่ผู้ใช้กำหนด

- อุปกรณ์มีฐานเดียวต่อ level group ทุกอาชีพใส่ร่วมกัน ยกเว้นชนิดอาวุธ
- Refine และ Enchant อยู่ประจำ slot เปลี่ยนของแล้วยังคงค่าเดิม
- การใส่การ์ดอยู่ประจำ slot มีขั้น/จำนวนช่องเพิ่มตาม Refine
- มี rarity 7 ขั้นและผสมของ 3 ชิ้นเพื่อเพิ่ม rarity หนึ่งขั้น

| อาวุธ | อาชีพตามบรีฟ |
| --- | --- |
| ดาบ | Swordsman, Knight, Crusader |
| ธนู | Archer, Hunter |
| คทา | Priest, Wizard |
| สมุด | Sage |
| หมัด | Monk |
| ขวาน | Merchant, Blacksmith |
| กระบอง | Alchemist |
| มีด | Assassin, Rogue |
| แส้ | Dancer |
| กีตาร์ | Bard |

อาวุธของ Acolyte/Mage ก่อนเปลี่ยนคลาสยังไม่ได้ระบุ และ Thief ยังไม่ได้ระบุชัดในตารางเริ่มต้น ข้อเสนอคือคทาสำหรับ Acolyte/Mage และมีดสำหรับ Thief แต่รอยืนยัน ไม่เพิ่ม Katar/หอกเป็นข้อบังคับเพียงเพราะ RO เดิมมี

P-05 กำหนด **6 slot: อาวุธ/หมวก/เกราะ/ชุดคลุม/รองเท้า/เครื่องประดับ** การมี assets โล่ไม่ได้เพิ่มช่องโล่แยกโดยอัตโนมัติ การแสดงโล่ของอาชีพบางสายเป็นรายละเอียดภาพได้ตามสกิล/บิลด์

## Tier

ใช้ tier เริ่มต้น Lv.1 แล้วมี **20, 40, 60, 80, 100** ตาม P-05 เปิดใช้ถึง cap ของ milestone นั้น Tier กับ Breakthrough เป็นคนละระบบ อนาคตเพิ่มแถวข้อมูลได้ ไม่ผูกความสามารถสูงสุดไว้ที่ Lv.100 ระดับอุปกรณ์ 100 ไม่ใช่ระดับเปลี่ยน Hi-class ซึ่งปรับเป็น 70 แล้ว

ของใน tier/slot เดียวกันใช้ฐานร่วมทุกอาชีพตามบรีฟ ความต่างจาก rarity/การพัฒนายังมีได้ ข้อเสนอให้เกราะเน้นค่าสากล เช่น HP/DEF แล้วแยกบิลด์ด้วย status, Enchant, การ์ด และสกิล ต้องตกลงว่าของมี random substat หรือไม่ก่อนเขียน loot table

P-05 มีทางอัป tier ชิ้นเดิมด้วยของ/วัตถุดิบ tier ใหม่เพื่อรักษา rarity สูตรต้นทุนยังต้องทำตาราง หากเปลี่ยนใส่คนละชิ้นใช้ rarity ของชิ้นนั้น ส่วน Refine/Enchant/การ์ดคงอยู่ที่ slot ตามเดิม

## Rarity และการผสม

| ขั้น | ชื่อ | สี |
| --- | --- | --- |
| 1 | Common | ขาว |
| 2 | Uncommon | เขียว |
| 3 | Rare | น้ำเงิน |
| 4 | Epic | ม่วง |
| 5 | Legendary | ทอง |
| 6 | Immortal | แดง |
| 7 | Supreme | ขาวรุ้ง |

ใช้ 3 ชิ้น rarity/tier/slot เดียวกัน → สูงขึ้นหนึ่ง rarity โดยอาวุธต้องชนิดเดียวกันตาม P-05 สูตรทอง/วัตถุดิบเพิ่มยังต้องออกแบบ ต้องพรีวิวผลและกันกินของที่สวม/ล็อกไว้

หากเริ่มจาก Common ทั้งหมดและไม่มีดรอประดับสูง การได้ Supreme หนึ่งชิ้นต้องใช้ `3^6 = 729` Common จึงต้องวัดเวลาได้ของจริงก่อนกำหนดอัตราดรอป/ต้นทุน การเพิ่ม tier ต้องไม่ทำให้การเก็บ rarity สูงเสียคุณค่าโดยไม่ได้ตั้งใจ

## การ์ด

ยืนยัน: การ์ดแต่ละ slot มีผลต่างกันและผูกกับ slot P-06 ใช้ 1 ช่องตั้งต้น ปลดช่องสองเมื่อ Refine +5 และช่องสามเมื่อ +10; รุ่นแรก Refine สูงสุด +10 ถอดสลับการ์ดนอกไฟต์ฟรี ของซ้ำใช้พัฒนาการ์ด

ต้องกำหนด: รายการหมวดการ์ด ระดับ/rarity ของการ์ดที่แยกจากเจ็ดขั้นอุปกรณ์ สูตรอัป การใช้การ์ดซ้ำในทีม การซ้อนผล และการ์ดที่แก้สกิล/เวลา เช่น ASPD/Cast Speed ให้มีเพดานที่ไม่ทำลาย rotation

เจ้าของความก้าวหน้ายืนยันแล้ว: Refine, Enchant และการ์ดเป็นข้อมูล slot บน NPC แต่ละตัว ไม่ใช่ช่องจัดทีม แยก item ที่ใส่ออกจากข้อมูลนี้ เพื่อเปลี่ยน NPC/เปลี่ยนของแล้วไม่ทำให้ความก้าวหน้าหายหรือถูกคัดลอกโดยไม่ตั้งใจ

## Artifact

ยืนยัน: ใส่ได้เมื่อ Hi-class เสริมสกิลเฉพาะอาชีพและ status เช่น ATK/DEX ได้ มี crystal gacha เกี่ยวข้อง

ยังไม่ตกลง: จำนวนช่อง การสลับ/อัป/ของซ้ำ ความเฉพาะอาชีพ วิธีได้ก่อน Hi-class ผลต่อสกิล Awaken และการใช้ proc หลายชั้น ต้องไม่ให้ผลเรียกสกิลวนไม่สิ้นสุด

Artifact อยู่ใน milestone ถัดไปร่วมกับ Hi-class/Awaken ตาม D-020 ไม่รวมในรุ่นแรกที่จบ Class 2
