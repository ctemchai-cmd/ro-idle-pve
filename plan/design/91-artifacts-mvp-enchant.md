# Artifact, MVP Hunt และ Enchant ช่วงท้าย — D203–205 / TASK179–182

ผู้ใช้ยืนยัน 2 Artifact ต่อคน, ผูกอาชีพและสกิล, มีเลเวลและดาว, หาจาก Crystal และ MVP Hunt/ดัน/หอคอย, เพิ่มรายได้ Crystal และความท้าทาย Enchant/บอส/หอคอย

## Artifact

แยกคลังจากอุปกรณ์ 500 ชิ้น ไม่แย่งช่องการ์ด; สวมได้ตั้งแต่ Hi-class และเก็บความก้าวหน้าต่อ NPC. 120 active skills มีชิ้นประจำสกิล; Common=Class1, Uncommon=Class2ปลด20, Rare=Class2ปลด30/40, Epic=Hiปลด70, Legendary=Hiปลด80. Rarity ประจำชนิด ไม่สุ่มเปลี่ยนสี. สองช่องต้องคนละสกิล; instance เดียวอยู่ได้คนเดียว. ใช้ภาพสกิลจริงของชิ้นนั้น พร้อมขอบ rarity และข้อมูลเพิ่มพลัง ไม่อ้างว่าเป็นภาพ Artifact ต้นฉบับ.

เลเวล1–10 ใช้ Essence/ทอง; ดาว0–5 กินชิ้นซ้ำชนิดเดียวกัน 1/1/2/2/3 ชิ้น. คืนทุนเลเวลของชิ้นที่ถูกกิน/ย่อยตามยอดจ่ายจริง. ล็อกและของสวมอยู่ห้ามกิน. บูสต์เฉพาะสกิลนั้นทั้ง base/Awaken ด้วยตัวแปลง resolved definition ร่วม runtime/headless/รายละเอียด. ไม่เปลี่ยนค่าสกิลพื้นฐานของคนที่ไม่สวม.

โบนัส Lv1→10: ขาว8→20%,เขียว10→25%,ฟ้า12→30%,ม่วง15→40%,ทอง20→50%; แต่ละดาวเพิ่ม10%ของโบนัสชิ้นนั้น (ทองเต็ม75%). ดาเมจ/ฮีล/โล่เพิ่ม power; บัฟและควบคุมเพิ่มระยะเวลา; Call Spirit เพิ่ม ATK ต่อบอลโดยไม่เพิ่มเพดานบอล. ต้องตรวจทุก active ทั้ง base/Awaken ว่ามีผลจริง.

สุ่มเลือกสาย Hi-class ใช้100Crystal/ครั้ง,10ครั้ง1000; ใช้ตั๋วก่อนCrystal. สี40/30/20/8/2%, ทองการันตีภายใน50ครั้ง ต่อเซฟ ไม่ใช้ pity ของการ์ด. รางวัลดัน/หอคอยเป็น Essence/ตั๋วใน claim เดิม, ไม่จ่ายย้อนหลัง.

## MVP Hunt

3บอสหมุนทุกสัปดาห์ตามเวลาBangkok,10ระดับต่อบอส. ลองได้ไม่จำกัด,รางวัลจ่ายเฉพาะส่วนของระดับสูงสุดที่เพิ่มในสัปดาห์นั้น. ใช้ shared battle engine และ checkpoint/receipt เดิม; ไม่มีการหักสิทธิ์ตอนเริ่ม. สัปดาห์ใหม่เปลี่ยน roster/สิทธิ์รางวัล ไม่ล้างตัวละคร. เปิดหลังผ่านบท8และมีHi-class. บอสใช้ native identity/ท่าที่มีจริง พร้อมธาตุและขนาด.
