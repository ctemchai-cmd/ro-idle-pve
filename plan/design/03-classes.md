# อาชีพ บิลด์ และทางต่อยอด

สถานะ: สายอาชีพและตารางเอกลักษณ์ใช้เป็นฐานตาม P-09 แล้ว ชุดสกิลตัวอย่างและค่ากลไกยังต้องทำ spec

## ขอบเขตจากผู้ใช้

Class 1 หกสาย เปลี่ยนเป็น Class 2 ได้ จากนั้นมี Hi-class และวางทางไป Class 3 ในอนาคต ทุกสายต้องมีทางเล่นหลายแบบผ่านสกิลและ status ไม่กำหนดว่าอาชีพหนึ่งทำได้บทบาทเดียว

เปลี่ยน Class 2 ที่ Lv.20, Hi-class ที่ Lv.70 และ Class 3 ที่ Lv.120 ตาม D-024 รุ่นแรกยังมีถึง Class 2 ส่วน Hi-class/Awaken/Artifact เป็น milestone ถัดไป ดู [ความก้าวหน้า](04-progression-and-equipment.md)

กติกาบิลด์ที่ยืนยันแล้ว: Active 4 ช่อง, Passive ที่เรียนมีผลอัตโนมัติ และใช้แต้มลง STR/AGI/VIT/INT/DEX/LUK เองทั้งตัวหลักและเพื่อน ไม่มีการโตของ status ตามอาชีพอัตโนมัติ จำนวนแต้มและสูตรแปลง status เป็นค่าต่อสู้ยังรอกำหนด

| Class 1 | Class 2 | แนวทางที่ผู้ใช้ให้ |
| --- | --- | --- |
| Swordsman | Knight | ดาเมจเดี่ยว, แทงก์/provoke, บัฟดาเมจเล็กน้อย |
| Swordsman | Crusader | แทงก์/provoke, ดาเมจ, บัฟความแข็งแกร่ง |
| Acolyte | Priest | ฮีล, บัฟเช่น AB/Im, ฟื้น mana, ดาเมจบางส่วน |
| Acolyte | Monk | ลูกบอล/คอมโบ/ต่อย, แทงก์ Steel Body/provoke |
| Archer | Hunter | ดาเมจเดี่ยวและหมู่, สถานะและลดเกราะ |
| Archer | Bard / Dancer | เลือกรูปลักษณ์ตามเพศที่ต้องการ, ฮีลหมู่/บัฟหมู่/debuff หมู่ |
| Thief | Assassin | ดาเมจเดี่ยว, พิษ/debuff; ขอช่วยแยกจุดเด่นจาก Rogue |
| Thief | Rogue | ดาเมจเดี่ยว, debuff/CC; ขอช่วยแยกจุดเด่นจาก Assassin |
| Merchant | Blacksmith | ดาเมจเดี่ยว/หมู่, บัฟทีมและ debuff |
| Merchant | Alchemist | ปายา/Hell Plant, ดาเมจหมู่, ฮีลเล็กน้อยจากต้นไม้, บัฟ/debuff |
| Mage | Wizard | เวทหมู่, สถานะ/CC; ขอช่วยแยกจุดเด่นจาก Sage |
| Mage | Sage | เวทเดี่ยว, บัฟทีม/CC; ขอช่วยแยกจุดเด่นจาก Wizard |

## ฐานเอกลักษณ์แต่ละอาชีพ

| อาชีพ | สิ่งที่ทีมเลือกอาชีพนี้มาแก้ | สายเล่นที่เสนอ | กลไกเฉพาะที่เสนอ |
| --- | --- | --- | --- |
| Knight | ยืนแนวหน้าและกดดันเป้าใหญ่ | จู่โจมเดี่ยว / แทงก์สวนกลับ | เตรียมจังหวะโจมตีหนัก, provoke แล้วโจมตีสวน |
| Crusader | คุ้มกันเพื่อนจากดาเมจหนัก | โล่คุ้มกัน / ดาเมจศักดิ์สิทธิ์ | รับส่วนหนึ่งของดาเมจแทนเพื่อน, เกราะป้องกันและโต้กลับ |
| Priest | กู้ HP และจัดการสถานะอันตราย | ฮีล/ชำระสถานะ / บัฟและฟื้น SP | ฮีลฉุกเฉินเป้าเดียวแข็งแรง, บัฟ/ฟื้นทรัพยากร; ดาเมจมีไว้รอง |
| Monk | สะสมทรัพยากรแล้วปิดด้วยท่าหนัก | คอมโบ/ลูกแก้ว / Steel Body แทงก์ | สะสมลูกแก้วจากท่าที่กำหนดแล้วใช้กับ finisher; โหมดถึกมี trade-off ด้านการรุก |
| Hunter | ดาเมจต่อเนื่องและกำจัดเป้าหมายสำคัญ | ยิง/คริติคอล / กับดักและสถานะ | ตีต่อเนื่องพ่วงนก, ทำเครื่องหมายเป้า หรือเตรียมกับดัก |
| Bard / Dancer | ทำให้หลายคนในทีมมีจังหวะและประสิทธิภาพดีขึ้น | เพลงบัฟ/ฮีลต่อเนื่อง / เพลง debuff | เพลง/การแสดงมีผลทั้งทีม, ช่วยเวลาร่าย/การฟื้นฟู; ฮีลฉุกเฉินด้อยกว่า Priest |
| Assassin | เจาะเป้าเดียวและสร้างดาเมจช่วงปิดเป้า | โจมตีเร็ว/คริติคอล / พิษสะสมแล้วระเบิด | พิษหรือจุดอ่อนสะสมสำหรับ finisher; ได้เปรียบเป้าที่เตรียมไว้ |
| Rogue | ลดศักยภาพศัตรูและขยายดาเมจทั้งทีม | เจาะจุดอ่อน / ขัดจังหวะและลอกท่า | Strip/Expose ลด ATK/DEF, debuff ทำให้ทีมตีแรงขึ้น, ท่าลอกแบบจำกัดรายการ |
| Blacksmith | เสริมทีมกายภาพและทำลายแนวป้องกัน | อาวุธหนัก/หมู่ / บัฟอาวุธและเกราะแตก | เสริม Normal Attack/ASPD หรือ ATK ทางกายภาพ, ทุบเกราะ/อาวุธ; ไม่ให้เป็นบัฟความเร็วทุกชนิด |
| Alchemist | คุมพื้นที่และสร้างผลต่อเนื่องจากสิ่งปรุง/สิ่งเรียก | สารเคมี/DoT / ต้นไม้ดาเมจและฮีล | ยาเปลี่ยนสถานะ, Plant ทำงานเป็นช่วงเวลา; กำหนดจำนวนและอายุเพื่อไม่ท่วมสนาม |
| Wizard | กวาดศัตรูหลายตัวและสร้างสนามเวทต่อเนื่อง | ระเบิดเวทหมู่ / เวทพื้นและควบคุม | เวทหมู่ลงแรงหรืออยู่บนสนาม, Freeze/Slow/พื้นที่อันตราย |
| Sage | เสริมความเสียหายต่อเนื่องและรับมือเวทศัตรู | Auto-bolt / Enchant และขัดเวท | ตีปกติพ่วงเวท, เสริมธาตุ/ความสามารถทีม, Spell Breaker/Dispel |

นี่เป็นแนวออกแบบของเกมเรา ไม่ใช่คำอธิบายว่าทุกอาชีพใน RO ทุกภาคทำตามตารางนี้อยู่แล้ว สกิลอย่าง provoke ของ Monk หรือการให้ Hell Plant ตั้งแต่ Alchemist ใช้ได้หากเราออกแบบไว้

## จุดต่างของสี่อาชีพที่ยังคิดไม่ลงตัว

### Assassin กับ Rogue

Assassin เน้นผลงานของตัวเองต่อเป้าหมาย: ตีเร็ว/คริ หรือวางพิษแล้วระเบิดตอนสะสมครบ ข้อเสนอชุดสี่ช่องตัวอย่างคือ เตรียมพิษ → เพิ่มความเร็วตนเอง → โจมตีหลายฮิต → ระเบิดพิษ ผลจริงและชื่อสกิลยังไม่ล็อก

Rogue เน้นเปลี่ยนเงื่อนไขให้ทีมได้เปรียบ: ลด ATK/DEF เปิดจุดอ่อน ทำให้ท่าบอสล้มเหลว หรือเลือกลอกท่าประเภทหนึ่งก่อนเข้าไฟต์ ชุดตัวอย่างคือ เปิดจุดอ่อน → โจมตีซ้ำจุดอ่อน → ลดความสามารถศัตรู → ท่าขัดจังหวะ อย่าให้บทบาทหลักเป็นพิษซ้ำกับ Assassin

RO PC มีพื้นฐาน Assassin ด้าน Sonic Blow/Enchant Poison/Venom Dust และ Rogue ด้าน Divest/Intimidate ส่วน Shadow Chaser ต่อยอด Reproduce/Shadow Spell จึงใช้เป็นแรงบันดาลใจได้ ดู [Assassin ทางการ](https://renewal.playragnarok.com/gameguide/classes_skill.aspx?c=12), [Rogue ใน iRO Wiki](https://irowiki.org/wiki/Rogue) และ [Shadow Chaser ทางการ](https://renewal.playragnarok.com/gameguide/classes_skill.aspx?c=50)

ถ้ามีการลอกสกิล เสนอให้เลือกจากรายการอนุญาตและใช้หนึ่งในสี่ช่อง ไม่เพิ่มช่องที่ห้าหรือคัดลอกทุกความสามารถอย่างไร้ขอบเขต ต้องกำหนด proc ไม่ให้เรียกกันวนไม่จบ

### Wizard กับ Sage

Wizard เหมาะกับแรงระเบิดหมู่และเวทที่ค้างบนสนาม: แลกเวลาร่ายกับพื้นที่/จำนวนเป้า ต้องการเพื่อนคุ้มกันและมีจังหวะใช้ท่าหนัก สายควบคุมใช้เวทน้ำแข็ง/พื้นที่หน่วง และ Chain CC ได้ตามกติกาปกติ เฉพาะบอสที่ใส่ Passive ตอบสนองต่อ CC จึงมีบัฟต้านตามข้อมูลของบอสนั้น

Sage เหมาะกับความถี่และการรับมือเวท: ถ้าเลือกสาย Auto-bolt จะได้ประโยชน์จาก Normal Attack ในช่วง SI/ACD ตามข้อสรุปผู้ใช้ และหยุดตีระหว่าง CT เช่นเดียวกับคนอื่น สายสนับสนุนเสริมธาตุ/เวทให้ทีมและมี Dispel/Spell Breaker ในระดับออกแบบของเรา ยังไม่ได้อนุมัติข้อยกเว้นตีขณะร่ายแบบ Free Cast แม้ RO ต้นทางจะมีสกิลนี้

Wizard เดิมมี Storm Gust/Quagmire และเวทหมู่ ส่วน Sage มี Hindsight, Free Cast, Endow และ Spell Breaker จริง ดู [Wizard ทางการ](https://renewal.playragnarok.com/gameguide/classes_skill.aspx?c=9) และ [Sage ทางการ](https://renewal.playragnarok.com/gameguide/classes_skill.aspx?c=15) การนำมาขัดบอสและสูตรเวลาในเกมนี้เป็นกติกาที่เราจะออกแบบใหม่ ไม่ยกข้อจำกัด/โอกาสสำเร็จเดิมมาใช้โดยอัตโนมัติ

## ทางต่อยอด Hi-class และ Class 3

ชื่อด้านล่างอ้างอิงสายอาชีพ RO PC; ชื่อบางภูมิภาคต่างกัน ใช้เป็นกรอบก่อนกำหนดชื่อแสดงในเกมเรา ดู [Classes — iRO Wiki](https://irowiki.org/wiki/Classes)

| Class 2 | Hi-class (ชื่อที่คุ้นเคย / ชื่อ iRO หากต่าง) | Class 3 | แนวขยายที่เสนอ |
| --- | --- | --- | --- |
| Knight | Lord Knight | Rune Knight | ท่าหนัก/สวนกลับลึกขึ้น แล้วขยายพลังรูน |
| Crusader | Paladin | Royal Guard | รับแทน/โล่ลึกขึ้น แล้วขยายการคุ้มกันทีม |
| Priest | High Priest | Arch Bishop | ฮีล/บัฟ/ชำระสถานะดีขึ้น แล้วขยายป้องกันทีม |
| Monk | Champion | Sura | ลูกแก้ว/finisher ดีขึ้น แล้วขยายคอมโบและสมดุลรุก/รับ |
| Hunter | Sniper | Ranger | ทำเครื่องหมาย/ยิง/นกลึกขึ้น แล้วเพิ่มสัตว์คู่หูและกับดัก |
| Bard | Clown / Minstrel | Maestro | เพลงทีมลึกขึ้นและขยายระบบการแสดง |
| Dancer | Gypsy | Wanderer | เพลง/debuff ลึกขึ้นและขยายระบบการแสดง |
| Assassin | Assassin Cross | Guillotine Cross | พิษ/finisher ดีขึ้น แล้วเพิ่มการแปร/กระจายพิษ |
| Rogue | Stalker | Shadow Chaser | ลอกท่า/Strip ดีขึ้น แล้วเพิ่มกลวิธี/ร่างเงา |
| Blacksmith | Whitesmith / Mastersmith | Mechanic | พลังอาวุธลึกขึ้น แล้วขยายเครื่องจักร |
| Alchemist | Creator / Biochemist | Geneticist | สารเคมี/Plant ลึกขึ้น แล้วขยายสิ่งเรียก/ปฏิกิริยา |
| Wizard | High Wizard | Warlock | ขยายพลังและการเตรียมเวท แล้วเพิ่มเวทผสม/ระเบิดขั้นสูง |
| Sage | Professor / Scholar | Sorcerer | Auto-bolt/ทรัพยากรเวทดีขึ้น แล้วขยายธาตุและวิญญาณธาตุ |

ตัวอย่างต่อยอดเป็นข้อเสนอ ยังไม่สร้างรายชื่อสกิลเต็ม ขอบเขตที่ยืนยันแล้วคือรุ่นแรกถึง Class 2 และ Hi-class/Awaken/Artifact เป็น milestone ถัดไป Class 3 ออกแบบไว้สำหรับอนาคต ไม่ใส่ Class 4 เพิ่มจากบรีฟ

## ประเด็นที่ต้องระวังเมื่อออกแบบสกิลจริง

- Knight กับ Crusader ต่างกันที่การยืนรุก/สวนกลับและการคุ้มกันเพื่อน ไม่ต่างกันเพียงค่า DEF
- Priest เป็นผู้กู้สถานการณ์ ส่วน Bard/Dancer เด่นที่ผลต่อหลายคนและจังหวะ ไม่ให้การฮีลแทนกันได้หมด
- Hunter เด่นยิงต่อเนื่อง/เป้าหมาย ส่วน Assassin เด่นเตรียมเป้าแล้วปิดช่วงดาเมจ และ Monk มีทรัพยากรลูกแก้ว/คอมโบ
- Hunter ช่วยชี้เป้า, Rogue ทำให้ศัตรูอ่อนแอ, Blacksmith เสริมทีมกายภาพ: แยกชนิด debuff และเพดานซ้อนเพื่อลดการทับหน้าที่
- Sage ต้องมีประโยชน์กับทีมและบอสหลายประเภท ไม่เป็นแค่ Wizard ที่เวทหมู่เบากว่า
- Bard/Dancer baselineที่ผู้ช่วยเลือกในTASK-005ใช้ชุดความสามารถเดียวกันต่างภาพ/อาวุธ ตามdataที่reviewแล้ว ไม่เพิ่มNPCคนที่สองและไม่บังคับเลือกเพศจากพลังที่เหนือกว่า
- การ์ด/status/Artifact ต้องสนับสนุนหลายบิลด์ ไม่มีอาชีพเดียวที่ให้ทั้งดาเมจสูงสุด ฮีล และคุมบอสครบจนแทนทุกคนได้
