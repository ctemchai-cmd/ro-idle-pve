# D171 — ระดับอุปกรณ์ตามด่านฟาร์ม

UI อ่าน `loot.gear.tier_by_chapter[stage.farm_rate_chapter]` ซึ่งเป็นแหล่งเดียวกับ storyFarmSnapshot. ห้ามใช้เลเวลบอส/ตัวละครหรือ card tier แทน. รวมเฉพาะด่านติดกันในบทเดียวกันที่ให้ระดับเดียวกันเป็นช่วง; ข้อมูลว่างแสดง —.

หน้าแรกแสดงระดับใต้ด่านฟาร์มเฉพาะเมื่อมี rate_snapshot. รางวัล AFK ใช้ `snapshot.gear_tier` เพื่ออธิบายช่วงที่กำลังสะสมตามข้อมูลที่ถูกแช่ไว้จริง. ไม่คำนวณใหม่ด้วยตารางของแพตช์ล่าสุดแทนช่วงเก่า.

แผนที่มี summary ระดับของบทที่กำลังดูและตารางทุกบทพับได้ อ่านบทที่ยังไม่ปลดได้โดยไม่ให้เข้าต่อสู้/ฟาร์มก่อนผ่าน. เลือกด่านแล้วแสดงระดับเหนือปุ่มฟาร์ม. ตารางไม่เรียก API/ไม่เขียนเซฟ. อัตราดรอป/พูล/RNG/กติกาทั้งหมดเดิม.

ค่าปัจจุบัน: บท1–2 Lv.1; บท3 Lv.20; บท4–5 Lv.40; บท6–12 Lv.60. ตัวเลขนี้อธิบายข้อมูลปัจจุบัน ไม่ใช่ mapping hardcode ใน UI.
