# Hi-class / Awaken — ขอบเขตปรับ23ต.ค.2026

D144–145:ผู้ใช้ทดสอบบาลานซ์เอง รอบปัจจุบันทำperformanceก่อน แล้วจึงออกแบบ/ทำHi-class. Hi-classที่70เพิ่มอาชีพละ2สกิลเท่านั้น;สกิลเดิมอัปเต็มก่อน70และสองท่าใหม่ต้องเต็มก่อน/ถึง90. D154แก้ความเข้าใจเดิมของผู้ช่วย: **Awakenเปิดเมื่อเป็นHi-class ไม่ใช่ล็อกทุกท่าที่90**. ยังไม่เลือกชื่อ/ผล/ราคา/Awakenvariantsของแต่ละอาชีพในเอกสารนี้;สัญญาปัจจุบันและผลตรวจอยู่[design45](45-hi-class-implementation.md).

## เพดานสกิล
กติกาสกิลเดิมmax10 cap=min(max,1+floor((characterLevel−1)/5)) จึงเต็มตั้งแต่46หากปลดท่าแล้ว;ต้องตรวจจริงทุกunlockก่อนเปิดHi-class. ไม่เลื่อนสกิลเดิมไปค้างที่70. สกิลใหม่ใช้gateจากunlockของตัวเอง ไม่ใช้สูตรเลเวล1เดิมจนปลดแล้วเต็มทันที.

ข้อเสนอเริ่มต้นสำหรับสกิลใหม่max10ตามปัจจุบัน:ท่าแรกunlock70/full88(capเพิ่มทุก2เลเวล),ท่าสองunlock80/full89(capเพิ่มทุกเลเวล). ดังนั้นทั้งสองเต็มที่89ก่อนAwaken90. นี่เป็นข้อเสนอunlock/stepของผู้ช่วย ยังไม่ใช่ตัวเลขที่ผู้ใช้ยืนยัน;ตารางและวัตถุดิบต้องออกแบบก่อนimplementation และการเต็มหมายถึงเพดานที่อัปได้ ไม่auto-upgrade/แจกทรัพยากร.

AwakenคงlogicalskillID/slotและใช้variantdefinition+paidledger/costversionของตัวเอง. D154–155ยืนยันเปิดเมื่อเป็นHi-classและต้องอัปสกิลเต็มก่อน;กลับสกิลLv1ที่แรงกว่าก่อนAwakenเต็ม ใช้เศษขั้นใหม่อัปต่อและเสริม/เปลี่ยนเอฟเฟกต์ ไม่ใช่แค่เพิ่มdamage. เศษขั้นใหม่ดรอปดันหลังๆ,รวมเศษเดิมเป็นเศษใหม่และย่อยใหม่กลับเดิมได้;อัตราแลกเป็นbaselineที่ต้องเขียนในtaskและห้ามวงแลกสร้างของเพิ่ม. การเลื่อนClass2→Hi-classในสายเดิมรักษาเลเวล/Status/สกิล/loadoutทั้งหมด ต่างจากการเปลี่ยนข้ามสายที่รีเซ็ตและคืนทุนเดิม.

## ภาพ
ใช้iconสกิลจากเกมตามbindingที่ยืนยันแล้ว เพิ่มขอบเส้นด้านในเรืองแสงสีม่วง(inner-line glow),ไม่แทนภาพด้วยไอคอนอื่น. CSSเป็นชั้นตกแต่งแยกจากภาพเพื่อให้ภาพต้นฉบับ/สีrarity/เลขสกิลยังอ่านง่าย. ต้องตรวจขนาด32–64pxและmobile;reduced-motionใช้แสงคงที่. ยังไม่มีCSSAwakenเปิดในรุ่นClass2.
