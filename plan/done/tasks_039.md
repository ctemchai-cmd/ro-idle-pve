## เป้าหมายและผลส่งมอบ

- ทุกหน้าตาม UX spec ที่ใช้เล่นได้จริง
- tutorial/ผลต่อสู้/ตั้งค่าเสียง/สถานะเซฟและหน้ารอระบบอนาคต

## ขอบเขต

- รวม: ผลลัพธ์ที่ระบุในชื่อและรายละเอียดงานนี้ตามข้อมูลรุ่นแรกที่ review แล้ว
- อยู่นอกงาน: การพัฒนาระบบ Hi-class/Awaken/Artifact, Class 3/Pet/Rune, dashboard หรือ AI ค้นบิลด์อัตโนมัติ; ส่วนอนาคตบันทึกจุดต่อไว้ตาม design

## รายละเอียด

ประกอบ UI ที่มีแล้วตาม wireframe และ game shell แนวตั้งเท่านั้นของ [design30](../design/30-game-shell-ui.md) (D-051/D-052) ให้เข้าออกแต่ละโหมด/แก้บิลด์/รับผลได้ครบ อ่านข้อมูลไทยบน desktop และจอเล็ก มีเพลง/เสียงตาม pack และตั้งค่าที่คงอยู่ รายงานแพ้ช่วยตัดสินใจปรับทีม

## ขั้นตอนทำงาน

1. เดินทุก player flow และแก้สถานะ/ปุ่ม/ข้อมูลที่ขาด
2. ทำผลต่อสู้/preview timing/tutorial/เสียงและตัวเลือกจำเป็น
3. ตรวจกรณี empty/loading/error/disconnect และการกลับมาเล่น
