# TASK-051 — ร้านค้า (Store) และกาชาอุปกรณ์

Milestone: M3 (งานแทรกตามคำขอผู้ใช้) · ประเภท: พัฒนา/ตรวจรับ · อ้างอิง: [D-063](../decisions.md), [equipment](../design/18-equipment-and-rewards-baseline.md)

## งานที่ต้องรอก่อนหน้า

- TASK-022 — คำสั่ง/receipt/seed ฝั่งเซิร์ฟเวอร์
- TASK-026 — inventory และนิยามไอเทม
- TASK-037 — กาชาการ์ด (รูปแบบ pity/ทำทีละใบใน command เดียว)
- TASK-052 — Option สุ่มตามระดับ (ของจากกาชามี option)

## เป้าหมายและผลส่งมอบ

เปิดปุ่ม Store ใน bottom bar: แท็บร้านขายของ (ทอง/crystal) และแท็บกาชาอุปกรณ์ (crystal, pity rarity) ผ่านคำสั่งเซิร์ฟเวอร์ที่มี receipt

## ขอบเขต

- รวมในงาน: ร้านขายวัตถุดิบ/อาวุธฝึกหัด/ของจำกัดต่อวันตามวันเซิร์ฟเวอร์, กาชาอุปกรณ์ 1/10 ครั้ง, pity, ของซ้ำเป็นไอเทมใหม่, ประวัติผลสุ่มใน receipt, UI มือถือ
- อยู่นอกงาน: เงินจริง (`purchase_with_real_money=false`), pet/artifact pool, ร้านแบบผู้เล่นซื้อขายกัน

## รายละเอียด

ราคา/อัตราเป็น baseline ของผู้ช่วยใน plan/data (ไม่ใช่ตัวเลขจาก RO) ทุกการสุ่มใช้ seed ของคำสั่งฝั่งเซิร์ฟเวอร์และ replay request เดิมไม่สุ่มใหม่ ของที่ได้ผ่าน inventory capacity เดียวกับ drop

## ขั้นตอนทำงาน

1. ข้อมูลและ schema ใน plan/data พร้อมตัวตรวจ
2. reducer/คำสั่งฝั่ง domain + unit tests
3. UI และ browser test
4. บันทึกหลักฐานและ acceptance

- [x] AC-03: ของจากกาชามี rarity/tier/option ตามกติกา D-062 และเข้าระบบอุปกรณ์เดิม (สวม/ผสม/อัป tier/ย่อย) ได้
